RUNTIME METRICS

指标趋势

按类别查看调用量、错误和耗时的走势，以及 JVM 内存、GC、CPU、线程、连接池和线程池等资源指标。资源指标直接读取 Spring Boot 已经配置好的 Micrometer 指标，不改变应用原有的指标导出。

调用次数和错误是每个时间点内的数量；平均耗时按调用次数加权，P95 由直方图估算（误差约 ±20%），按分钟显示时不计算 P95。资源指标是每分钟采样，较长范围取平均；GC 次数和停顿时间是每分钟的量。点击图例可开关曲线。
