RUNTIME METRICS

指标趋势

先看服务概览的请求量、错误率和耗时，再对照 CPU、内存、GC、线程池、连接池和磁盘等资源指标定位原因；单个接口、SQL 的调用量和耗时趋势在“调用排行”中点开一行查看。资源指标直接读取 Spring Boot 已经配置好的 Micrometer 指标，不改变应用原有的指标导出。

资源指标每分钟记录一次，CPU、忙碌线程、活跃连接、排队等饱和度指标每 10 秒采样，同时记录平均值和峰值。较长范围内，次数和流量求和，峰值取最大，上限取最新值，其余取平均。点击图例可开关曲线，点击分组标题可展开或收起。

调用排行 指标趋势
历史存储：读取中

每个实例各自保存历史，位于存储目录的 metrics/ 下：最近 2 天保留细粒度数据，更早的按小时（调用）或 10 分钟（资源）合并；保留天数和容量上限由 meerkat.metrics.retention 和 max-storage-size 决定。
